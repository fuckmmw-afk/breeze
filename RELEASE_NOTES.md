1.2.0: автоматизации по сети — в Настройках → Автоматизации задаётся сервер или группа серверов для Wi‑Fi и для сотовой сети (группа — по словам в названии, например «LTE», и/или вручную). Туннель сам переключается при подключении и при смене сети, даже с закрытым приложением, сразу проверяет задержку группы и включает самый быстрый сервер. Пинг потоком: серверы проверяются сразу по нескольку (8–64, настраивается), результат каждого появляется сразу, возле сервера крутится индикатор, пока ждём ответ. Свайп влево по серверу — проверить только его (и при включённом VPN, через ядро). Переключатель темы: Авто / Светлая / Тёмная.
